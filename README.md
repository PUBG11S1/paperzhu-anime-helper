# Paper朱二次元渲染助手 / Paper Anime Render Helper

为二次元角色展示提供描边、卡通阴影、材质高光、色彩管理、辉光与卡通天空盒工具。

## 当前进展（2026-10-21）

当前本地开发版本为 **2.5.0**，已完成扩展格式适配、跨版本兼容和卡通天空盒功能。详细记录见 [开发进展](PROGRESS.md)。

> 本次更新同步开发进展文档。仓库现有 V1.0/V2.0 文件保留为历史版本；2.5.0 源码与安装包尚未在本仓库发布，不能把历史 ZIP 当作 2.5.0 下载。

## 已完成功能

- 一键添加黑色描边，支持粗细调节及可选描边修复。
- 二次元色彩管理与对比度预设。
- 可调节的风格化材质高光。
- Eevee 卡通阴影：支持明暗阈值、柔和度、阴影强度、光照影响和最低亮度。
- 卡通阴影可恢复原始材质表面连接，保留支持材质的基础颜色、透明度和法线连接。
- 一键搭建合成器辉光，兼容不同 Blender 代际的节点实现。
- 卡通天空盒：内置 2048×1024 海天全景图，也可手动选择本地 HDR、EXR、PNG、JPG 或 WebP。
- 天空盒强度与水平旋转实时调节，并可一键恢复此前的 World。
- 英文默认界面与中文翻译。

## 安装扩展包

获得相应版本的扩展 ZIP 后：

1. 打开 **编辑 → 偏好设置 → 获取扩展（Get Extensions）**。
2. 在右上角菜单选择 **从磁盘安装（Install from Disk）**。
3. 选择 ZIP 并启用扩展。
4. 在 **3D 视图 → N 侧栏 → Paper Anime** 使用工具。

## 使用说明

- 卡通阴影面向 Eevee 和支持的 Principled 材质；复杂节点图可能会被跳过。
- “光照影响”控制卡通阴影跟随场景光照亮度的程度；“最低亮度”用于减轻未受光区域完全变黑。
- 内置天空图是 **LDR 全景图**，适合卡通背景和近似环境光。需要真实高动态范围照明时，请手动选择 HDR/EXR。
- 天空盒会创建扩展管理的 World，原 World 保留供“恢复”按钮使用。
- 不同模型、透明材质和法线状态仍可能影响效果，重要工程建议先在副本中试用。
